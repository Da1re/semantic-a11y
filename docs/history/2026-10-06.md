## 결정
- 큰 시장용 제품이 아니라 "내가 쓰고 싶은 작은 도구"로 만든다
- 유사 도구가 있어도 바퀴부터 직접 만든다. 차별점 = AI 의미 판정 + KWCAG
- 1차 형태는 MCP 서버(판정은 사용자 에이전트), 크롬 확장은 2차 선택
- 리포트 언어 선택: ko(KWCAG 기준) / en(WCAG 기준)
- 리포트 출력 형식: md / pdf(Playwright로 인쇄) / json
- GitHub 이슈는 치명 위반만 자동 생성, 나머지는 대시보드 버튼. 위반 지문으로 중복 방지·자동 닫기
- 대시보드는 로컬 실행 기본(사내 서버 선택), 검수 대기열·권한은 GitHub 이슈 라벨·저장소 권한 재사용. 공개 호스팅(GitHub Pages)은 쓰지 않음
- 이름은 semantic-a11y로 확정 (한·영 리포트를 지원해 kwcag 이름은 범위보다 좁음. KWCAG는 설명·키워드·토픽으로 노출)
